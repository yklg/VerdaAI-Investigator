平台采集
各平台 Cookie，用于舆情抓取
  1. 用电脑浏览器（Chrome / Edge / 火狐）打开并登录对应平台网页版。
  2. 按 F12 打开开发者工具 → Network（网络） → 刷新页面 → 左侧点任意该域名请求。
  3. 右侧 Headers → Request Headers → Cookie，整行复制（形如 name1=v1; name2=v2; …），粘进对应框保存。
抖音 (www.douyin.com)
sessionid / sid_tt / sid_ucp_v1 / passport_csrf_token / odin_tt / s_v_web_id
小红书 (www.xiaohongshu.com)
a1 / web_session / webId / gid
B站 (www.bilibili.com)
SESSDATA / bili_jct / buvid3 / DedeUserID

嫌手动复制麻烦？用本项目附带的「Cookie 导出扩展」（cookie-export-helper/），在已登录页面点一下即复制全部 Cookie（含 httpOnly）。

⚠️ Cookie 含登录态，勿泄露、勿提交到公开仓库；部分平台会过期，失效后重新复制一次即可。
